# Todo Manager 升级说明

2026-11-10 发布，适用于 Apple 芯片的 Mac（arm64）。本包同时提供 `TodoManager.app` 和命令行程序 `todo`。应用信息中的版本号沿用 0.1.0，请用发行日期和 ZIP 的 SHA-256 区分本次构建。本包未使用 Apple Developer ID 签名，也未经过 Apple 公证。

## 替换旧版

1. 退出 Todo Manager，并等正在写入任务的 CLI 命令结束。
2. 备份原数据目录。macOS 发行版默认保存在 `~/Library/Application Support/TodoManager/data/`，可在 Finder 按 Shift–Command–G，粘贴该路径后复制整个目录。若一直使用 `--data-dir`，备份指定目录。若此前使用源码版，默认数据通常在源码仓库的 `data/` 下。
3. 将 ZIP 完整解压到新文件夹，保留旧程序以便回退。双击新文件夹内的 `TodoManager.app`。命令行进入同一文件夹后，先执行 `./todo completed --help` 确认使用的是新版 CLI。若原有命令别名或 PATH 指向旧版，请同步更换。系统的应用打开策略可能要求管理员批准。
4. 原先使用发行版默认目录的用户，首次打开即可读取旧任务。若使用自定义数据目录，请给 APP 和 CLI 指定同一目录：

   ```bash
   open -n ./TodoManager.app --args --data-dir "/你的任务数据目录"
   ./todo list --data-dir "/你的任务数据目录"
   ```

## 本次变化

- 跨日后自动更新“今天”。月历继续显示原先选中的日期，编辑草稿也会保留。
- 修改状态后，月历留在所选日期。切换筛选后仍选中原任务时，保留未保存的修改。
- 父、子任务从新版开始记录状态变化。编辑子任务 A、再新增子任务 B 后保存，两者均可持久化。仅在状态真正变化时增加事件，重复保存不会重复计数。
- 旧任务继续可用。升级前的完成时间不回填，升级后的变更才进入回溯查询。

## 查询期间完成情况

以下示例查询 11 月的子任务。日期按查询设备的本地日期计算，包含首尾两天。使用自定义目录时，两条命令都要带上相同的 `--data-dir`。

```bash
./todo completed --from 2026-11-01 --to 2026-11-30 --level subtask
./todo status-history --from 2026-11-01 --to 2026-11-30 --level subtask --to-status 已完成
```

第一条按任务汇总完成次数，第二条逐次列出完成事件。省略 `--level` 可同时查询父、子任务。追加 `--json` 可获得机器可读结果。

## 回退

退出新版并另存当前数据目录，保留升级后的任务和事件。使用旧程序时恢复升级前的备份，或给旧程序指定一份单独的备份目录。升级后的修改只保存在新版数据中。
