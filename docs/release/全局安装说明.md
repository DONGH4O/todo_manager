# 全局安装 Todo Manager 的 `$todo` 技能

适用于 Apple 芯片的 Mac。完整解压发行包，在终端进入包含 `TodoManager.app`、`todo` 和 `skills` 的 `TodoManager` 文件夹。执行以下两行，将技能、命令手册、返回样例和配套 CLI 一起安装到当前 Codex 用户目录。

```bash
mkdir -p "${CODEX_HOME:-$HOME/.codex}/skills"
ditto skills/todo "${CODEX_HOME:-$HOME/.codex}/skills/todo"
```

默认安装位置为 `~/.codex/skills/todo`。再次执行会更新其中的同名文件。如果你自行编辑过旧技能，请先备份该技能文件夹。任务数据另存于桌面 APP 的数据目录。

在另一个项目打开新的 Codex 会话，输入 `$todo 查询今天完成过哪些任务`。技能会选用 `completed`；一天内没有完成记录时，返回空清单。各项目默认共用桌面 APP 的任务库，使用自定义任务库时可在请求中指定 `--data-dir`。

可在任意项目目录运行以下命令，核对安装后的 CLI 是否提供完成查询：

```bash
"${CODEX_HOME:-$HOME/.codex}/skills/todo/scripts/todo" completed --help
```

技能目录中的 `SKILL.md` 说明如何选命令，`references/cli.md` 介绍 17 条命令的参数和统计口径，`references/examples.md` 收录实测返回样例。桌面 APP 和任务数据的升级步骤见同一发行包内的《升级说明》。
